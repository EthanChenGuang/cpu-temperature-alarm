# CPU 高温报警 — 安装与使用说明

> 适用版本：**v6.17** 及相近版本  
> 程序目录示例：`D:\projects\cpu-temp-alert\`  
> 最新推荐程序：`cpu-temp-alert-v6.17.exe`

---

## 一、程序是做什么的？

本程序在 Windows 系统托盘运行，实时读取 CPU / GPU 温度（通过内置 LibreHardwareMonitor），并在温度过高时：

- 在托盘图标上显示**当前峰值温度数字**
- 播放**本地蜂鸣**（可在设置中关闭）
- 弹出**屏幕 Toast 提示**（约 5 秒自动消失）
- 通过 **WhatsApp（CallMeBot）** 发送报警消息（需配置）

---

## 二、系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11（64 位） |
| .NET Framework | **4.7.2 或更高**（LibreHardwareMonitor 需要） |
| 管理员权限 | **建议始终以管理员身份运行**（CPU 温度传感器需要 MSR 访问） |
| 网络 | WhatsApp 报警需要联网；本地蜂鸣不需要 |
| 其他 | 不要与官方 **LibreHardwareMonitor.exe** 同时运行（会争抢驱动，读数不准） |

## 四、第一次启动前的必做步骤

### 步骤 1：准备配置文件

若 `config\config.json` 不存在，请创建 `config` 文件夹并新建该文件。

可参考以下内容（**务必修改标注为「必改」的项**）：

```json
{
  "whatsapp_phone": "+393889399929",
  "callmebot_api_key": "你的 CallMeBot API Key",

  "threshold_celsius": 85,
  "critical_tiers_celsius": [90, 95],
  "cooldown_seconds": 180,
  "poll_interval_seconds": 3,

  "beep_frequency_hz": 1000,
  "beep_duration_ms": 500,
  "beep_burst_count": 2,
  "beep_burst_gap_ms": 200,
  "beep_interval_seconds": 10,
  "critical_beep_burst_count": 3,
  "critical_beep_interval_seconds": 30,
  "mute_duration_seconds": 900,
  "sound_alerts_enabled": true,

  "alert_message_template": "CPU/GPU ALERT: Peak temperature {peak_temp}°C exceeds threshold {threshold}°C on {hostname}. [{timestamp}]"
}
```

**用记事本编辑：**

```powershell
notepad D:\projects\cpu-temp-alert\config\config.json
```

### 步骤 2：配置 WhatsApp（CallMeBot）【必改，若需远程报警】

#### WhatsApp 版 API 获取步骤

1. **添加 CallMeBot 机器人联系人**  
   在手机通讯录里添加 CallMeBot 机器人的 WhatsApp 号码。  
   官方教程页（[callmebot.com](https://www.callmebot.com/blog/free-api-whatsapp-messages/)）给出的号码之一是 **+34 684 73 40 44**。  
   其他页面也可能显示不同号码，说明号码可能会更新，**请以你当前打开的官方教程页为准**。

2. **发送激活消息**  
   打开 WhatsApp，给该联系人发送下面这句**英文**（需完全一致）：

   ```
   I allow callmebot to send me messages
   ```

3. **获取 API Key**  
   等待机器人回复。你会收到一条包含类似以下内容的消息：

   > API Activated for your phone number. Your APIKEY is ...

   消息里 **`Your APIKEY is` 后面的字符串** 就是你的 **API Key**，请妥善保存。

4. **若未收到回复**  
   若 **2 分钟内** 没有收到机器人消息，官方说明建议 **24 小时后再试一次**。

5. **写入本程序配置**  
   拿到 API Key 后，在 `config.json` 中填写：
   - **`whatsapp_phone`**：你的手机号，国际格式，以 `+` 开头（与 WhatsApp 激活时使用的号码一致），例如 `+393889399929`
   - **`callmebot_api_key`**：上一步获得的 API Key  

   该 Key 也可用于 CallMeBot 的 WhatsApp 接口 URL 发送消息；本程序会在超温报警时自动调用。

> CallMeBot 免费版约 **48 条/天**。超出后程序会自动暂停 WhatsApp 发送并在日志中提示。

### 步骤 3：设置报警阈值与声音【建议首次修改】

| 配置项 | 说明 | 建议值 |
|--------|------|--------|
| `threshold_celsius` | 超过该温度开始报警 | 70～90（按机器散热情况） |
| `sound_alerts_enabled` | 是否启用蜂鸣 | `true` / `false` |
| `beep_interval_seconds` | 蜂鸣间隔（秒） | 10 |
| `poll_interval_seconds` | 温度刷新间隔（秒） | 1～3 |

也可在程序运行后通过 **Settings 对话框** 修改（见下文），保存后写入 `config.json`。

## 五、配置参数详解

### 5.1 温度与报警逻辑

| 参数 | 类型 | 范围/默认 | 说明 |
|------|------|-----------|------|
| `threshold_celsius` | 整数 | 1～150，默认 85 | 主报警阈值（°C） |
| `critical_tiers_celsius` | 数组 | 如 [90, 95] | 更高档位，触发更急促蜂鸣 |
| `cooldown_seconds` | 整数 | ≥30，默认 180 | 同一档位 WhatsApp 重复发送的最小间隔 |
| `poll_interval_seconds` | 整数 | 建议 1～10 | 传感器轮询间隔 |

**报警行为简述：**

- 峰值温度 **≥ threshold**：开始蜂鸣（若启用）、Toast、尝试发 WhatsApp  
- 峰值温度 **< threshold**：停止蜂鸣，记录“恢复正常”  
- 温度降至阈值以下即停止蜂鸣（无滞后）

### 5.2 声音（蜂鸣）

| 参数 | 说明 |
|------|------|
| `sound_alerts_enabled` | `true`=有蜂鸣；`false`=永久静音（WhatsApp 不受影响） |
| `beep_frequency_hz` | 蜂鸣频率（Hz），200～5000 |
| `beep_duration_ms` | 单次蜂鸣时长（毫秒） |
| `beep_burst_count` | 每次报警连响次数（普通档） |
| `beep_burst_gap_ms` | 连响之间的间隔 |
| `beep_interval_seconds` | 两组蜂鸣之间的间隔（普通档） |
| `critical_beep_burst_count` | 临界温度档连响次数 |
| `critical_beep_interval_seconds` | 临界温度档蜂鸣间隔 |
| `mute_duration_seconds` | 托盘菜单「临时静音」时长（秒），默认 900（15 分钟） |

### 5.3 WhatsApp 消息

| 参数 | 说明 |
|------|------|
| `whatsapp_phone` | E.164 格式，必须以 `+` 开头 |
| `callmebot_api_key` | CallMeBot API 密钥 |
| `alert_message_template` | 消息模板，可用占位符：`{peak_temp}` `{threshold}` `{hostname}` `{tier}` `{timestamp}` |

## 六、日常使用教程

### 6.1 启动程序

- **推荐：** 双击桌面快捷方式 **CPU Temp Alert**（需已指向最新 exe）  
- 或运行：`D:\projects\cpu-temp-alert\cpu-temp-alert-v6.17.exe`  
- **务必接受 UAC 管理员提示**，否则 CPU 温度可能读不到或不准  

### 6.2 托盘图标

- 显示当前**峰值温度**（整数，如 `82`）  
- 超温报警时数字变为**红色**  
- 鼠标悬停可看到更精确温度（如 `Peak: 82.0°C`）

### 6.3 右键菜单

右键托盘温度数字，弹出菜单：

| 菜单项 | 说明 |
|--------|------|
| 传感器列表 | 只读，显示各传感器当前温度 |
| Mute sound 15 min | 临时静音 15 分钟（仅当 Settings 中 **Sound alerts** 开启时显示） |
| Open Settings | 打开设置窗口 |
| Exit | 退出程序 |

> 本程序使用**非模态浮层菜单**（非系统原生菜单），以便在菜单打开时其他软件的全局热键仍可正常使用。

### 6.4 设置窗口（Settings）

右键 → **Open Settings**，可修改：

| 设置项 | 说明 |
|--------|------|
| WhatsApp phone | 手机号（E.164） |
| CallMeBot API key | API 密钥（带 👁 显示/隐藏） |
| Alarm threshold (°C) | 报警阈值 |
| Sound alerts | 勾选=蜂鸣开启；取消=永久静音 |
| Start with Windows | 开机自启 |

点击 **Save** 保存到 `config\config.json`；**Cancel** 放弃修改。

### 6.5 退出程序

右键托盘 → **Exit**。退出后蜂鸣停止，托盘图标消失。

## 七、日志与故障排查

### 日志文件

```
D:\projects\cpu-temp-alert\cpu-temp-alert.log
```

常用日志含义：

| 日志 | 含义 |
|------|------|
| `Temperature alert: peak=...` | 已触发超温报警 |
| `Local beep active: ...` | 蜂鸣已启动 |
| `WhatsApp alert sent` | WhatsApp 发送成功 |
| `CallMeBot daily message limit reached` | 今日 WhatsApp 配额用尽 |
| `WhatsApp paused` | 暂停 WhatsApp 发送 |

### 常见问题

**Q：托盘没有温度数字？**  
- 确认已以**管理员**运行  
- 关闭官方 LibreHardwareMonitor  
- 查看 `cpu-temp-alert.log` 是否有传感器错误  

**Q：温度与官方 LHM 不一致？**  
- 不要同时运行两个程序  
- 确认 `poll_interval_seconds` 不要太长  

**Q：没有蜂鸣？**  
- 检查 Settings 中 **Sound alerts** 是否勾选  
- 检查是否点了「Mute sound 15 min」  
- 确认温度确实 ≥ `threshold_celsius`  

**Q：没有 WhatsApp？**  
- 检查 `config.json` 手机号与 API Key  
- 运行 `--test-whatsapp` 测试  
- 查看是否达到 48 条/日上限  

**Q：启动报错 “Failed to start embedded python interpreter”?**  
- exe 可能损坏，请重新复制最新版 `cpu-temp-alert-v6.17.exe`  
- 确保从本地磁盘运行，不要从不稳定网络路径启动  

**Q：右键菜单没反应？**  
- 请使用 **v6.15 及以上** 版本  
- 若仍无效，重启程序后再试  

**Q：开机没有自动启动？**  
- 打开 **设置 → 应用 → 启动**，确认 **CPU Temp Alert** 已开启  
- 程序需要**管理员权限**才能读取 CPU 温度；开机自启快捷方式必须勾选 **以管理员身份运行**（在 Settings 里取消再重新勾选 **Start with Windows** 可自动修复）  
- 登录后若弹出 UAC 提示，请点击 **是**（仅首次或策略变更时可能出现）  
- 自启后会等待约 30 秒再启动，避免系统托盘尚未就绪

## 九、升级到新版本

1. 退出旧程序（托盘 → Exit）  
2. 将新版本 exe 复制到 `D:\projects\cpu-temp-alert\`

5. **`config\config.json` 无需删除**，设置会保留
