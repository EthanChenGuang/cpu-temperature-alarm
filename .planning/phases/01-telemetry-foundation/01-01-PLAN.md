## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub release → fetch-lhm.ps1 | External binary download crosses network trust boundary |
| vendor/*.dll → pythonnet clr | Local DLL load executes native/.NET code in process |
| LHM driver → hardware sensors | Kernel/driver layer reads hardware; requires possible admin elevation |
